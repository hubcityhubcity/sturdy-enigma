# Private technical validation source

A user-provided 81.7-second horizontal MP4 is being used only in the isolated product-validation environment. It is not committed to this repository, not uploaded to GitHub Actions, not published, and not used as a product demo asset.

The source is used to verify:

- FFmpeg can read its H.264 video and AAC audio streams
- a vertical MP4 can be rendered from real uploaded media
- future configured transcription results are tied to the uploaded source rather than demo text
- caption and packaging outputs stay associated with the same source and candidate

This note deliberately excludes the source title, channel, participants, transcript, and any publication or distribution claim.
